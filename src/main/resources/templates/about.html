Original project

This was a degree group project for Meteor Eyewear in 2024–2025. The group used Oracle and Microsoft Azure. Access to the original accounts was later lost.

This version

The system was rebuilt in 2026 using the remaining documents, HTML pages and images. It includes accounts, frames, lenses, spectacle profiles and orders. H2 is used for the local database. All demo customer details are made up.

Some layouts and code differ from the original. Google/Facebook login, notifications, payments and image uploads are not included. The old database and Azure setup have not been restored.
